## 🧩 How the Solutions Work

The files in this repository contain **solution snippets intended to be copied and pasted directly into the HackerRank code editor**.

The HackerRank environment provides the necessary input functions and predefined code structure.

For example:

```javascript
function main() {
  var i = 4;
  var d = 4.0;
  var s = "HackerRank ";

  var secondInt;
  var secondDouble;
  var secondString;

  secondInt = parseInt(readLine());
  secondDouble = parseFloat(readLine());
  secondString = readLine();

  console.log(i + secondInt);
  console.log((d + secondDouble).toFixed(1));
  console.log(s + secondString);
}
```

> These solutions may not run directly in a local Node.js environment because functions such as `readLine()` are provided by HackerRank.
